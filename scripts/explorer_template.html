How to read the evidence
  • Movement and section plots use the latest recorded actual arrival/departure fields; forecasts in the case study are reconstructed as of each poll. Values can be revised by the source.
  • Automatic flags are preserved. They are the normal feed behaviour, not a reason to exclude a time.
  • A station code can occur as both a passenger stop and a timing point in the same response (notably Pearse). Passenger-stop rows take precedence; the extra timing point is not a second passenger visit. Board evidence is used only if no passenger-stop row exists.
  • Unresolved E111 is not included in these curves. Its LocationType=C is undocumented; cancellation is not assumed.
  • Missing times break movement lines. Section calculations require complete non-negative actual and scheduled durations. Charts use a 30-minute trial-boundary buffer for section statistics. No outliers are silently trimmed.
  • Operational timing points outside the passenger-station list remain in the original archive, but are not plotted as passenger stops.
  • One trial day cannot establish typical behaviour, complete timetable coverage, causality, crowding or rolling-stock connections. Journey boundaries are incomplete.
